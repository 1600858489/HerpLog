# PostgreSQL and Redis Development Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove SQLite entirely, run development and tests against the PostgreSQL development container, initialize an optional Redis connection pool, and manage PostgreSQL schema changes with Alembic migrations.

**Architecture:** The application owns one process-level SQLAlchemy async engine/session factory and one process-level `redis.asyncio.Redis` client. PostgreSQL is required and is initialized through `alembic upgrade head`; Redis is probed during lifespan when available, but Redis failure does not prevent application startup because no current business flow depends on it. Tests use an isolated PostgreSQL test database and the same migration metadata, with independent engine/client cleanup.

**Tech Stack:** Python 3.12+, FastAPI, SQLAlchemy 2 async, PostgreSQL 17, asyncpg, Alembic async migrations, redis-py asyncio client, pytest, pytest-asyncio, Docker Compose.

## Global Constraints

- Development and test environments do not support SQLite or `aiosqlite`.
- PostgreSQL connections use `postgresql+asyncpg://` and are managed by an explicit SQLAlchemy pool.
- Alembic is the only mechanism for application schema creation and changes; runtime `Base.metadata.create_all()` is removed from application startup.
- Redis is infrastructure-only in this change; no cache, rate limiting, token blacklist, session, or task-queue behavior is added.
- Redis initialization failure is logged and tolerated; Redis client shutdown always closes its pool when a client was created.
- Tests use a PostgreSQL database isolated from development data and execute migrations before tests.
- Do not commit `.env` or any real credentials.
- Before any test-database command, load the ignored local environment and derive the isolated URL without printing credentials:

```bash
set -a; . ./.env; set +a
export TEST_DATABASE_URL="postgresql+asyncpg://${POSTGRES_USER}:${POSTGRES_PASSWORD}@127.0.0.1:5432/herplog_test"
```

from redis.asyncio import Redis


def create_redis_client() -> Redis:
    return Redis.from_url(
        settings.redis_url,
        max_connections=settings.redis_max_connections,
        socket_connect_timeout=settings.redis_connect_timeout,
